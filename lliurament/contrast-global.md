## 2. Com respondre

Cada aspecte té quatre camps curts:

- **Previsió inicial:** Sí / Parcialment / No. Expliqueu què deia la metodologia abans del curs.
- **Aplicació real:** Aplicat / Aplicat parcialment / No aplicat / Encara no comprovat / No aplicable. Expliqueu què va passar i amb quin resultat.
- **Evidència:** un identificador del registre de l'apartat 4, o «Sense evidència». Un enllaç ha d'indicar què demostra.
- **Decisió:** Mantenir / Millorar / Incorporar / No adoptar / Pendent de comprovar, amb un motiu concret.

Una frase o dues per camp solen ser suficients. Distingiu el que vau fer abans del curs del que heu canviat després. **Tenir-ho escrit no demostra haver-ho aplicat.**

Podeu reutilitzar una evidència en diversos aspectes. No cal instal·lar eines, canviar d'agent, crear habilitats ni desenvolupar un MVP per respondre. Si només heu treballat una funcionalitat, identifiqueu què encara no heu pogut comprovar. «No aplicable» requereix una justificació.

Compareu funcions dels documents i decisions; no cal reproduir els noms ni les eines del curs.
