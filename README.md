# DAW2 · Sprint 1.2 · Guia de lectura compartida

Materials per seguir a classe el curs [Spec-Driven Development with Coding Agents, de DeepLearning.AI](https://www.deeplearning.ai/courses/spec-driven-development-with-coding-agents/), de **76 minuts**.

## Finalitat

Contrastar les idees dels vídeos amb la metodologia pròpia per programar amb agents que heu definit amb **OpenSpec** a l'Sprint 1.2 i aplicat sobre una funcionalitat que ja havíeu desenvolupat amb altres metodologies.

La finalitat és identificar què ja havíeu previst, valorar com us ha funcionat i decidir si introduiríeu millores. Les decisions s'han de justificar amb l'experiència pràctica; també podeu argumentar per què manteniu la vostra metodologia.

## Lliurament del contrast

Utilitzeu la [plantilla de contrast final](lliurament/contrast-global.md), amb tres parts: **la metodologia que vau definir**, **l'experiència sobre la funcionalitat** i **la revisió després del curs**. La metodologia i la seva aplicació tenen la mateixa importància. El contrast se centra en requisits, planificació, treball amb l'agent, validació i integració amb GitHub.

Les preguntes de cada fitxa ajuden a seguir els vídeos. **No cal lliurar també les taules de les fitxes:** les respostes es recullen una sola vegada a la plantilla global.

## Com treballarem

1. Seguim el vídeo i consultem els conceptes i els diagrames de la fitxa.
2. Contrastem les propostes amb la metodologia i l'aplicació pràctica de l'Sprint 1.2.
3. Posem en comú les conclusions i justifiquem les possibles millores.

Les fitxes de lectura contenen tres apartats: **conceptes clau per dominis**, **mapes o diagrames** i **taula de contrast**. Els termes es mantenen en anglès, amb les explicacions i les traduccions en català.

L'apartat **04 · Entorn de treball** és una excepció: seguirem l'ordre del curs, però cadascú pot triar el seu IDE i agent de programació. La fitxa serveix per documentar-ne la configuració i comprovar que l'entorn està preparat.

L'apartat **05 · Setup** també té un format específic: enllaç al vídeo i síntesi de les frases fonamentals amb marques de temps.
